# `\p` property support

| Engine | Property support |
| --- | --- |
| ICU4C | full support |
| Perl | full support + Perl extensions |
| Java | GC, Script, Binary, Block + Java ext. |
| Onigmo | GC, Script, Binary, Block, Age |
| PCRE | GC, Script |
| Oniguruma | GC, Script |
| .NET | GC, Block |

Unsupported: Python, JavaScript
