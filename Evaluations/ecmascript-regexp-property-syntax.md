notes: "Braces are mandatory (\\pL/\\PL are invalid) and = is the only name/value separator. An omitted property name means a General_Category value, a listed binary code-point property or (v only) a listed string property; script names cannot be used alone. Exact table/UCD aliases only, with no Is/In prefixes, whitespace, case folding, hyphen/underscore normalization, colon separator or internal ^ negation. Binary membership uses \\p{...} and complement uses \\P{...}; =Yes/=No/=True/=False assignments are rejected. WSpace is not listed; White_Space and space are. Under i, u complements a property set before folding, whereas v folds before complementing; these can produce different \\P matches. String-property \\P and negated classes that may contain strings are syntax errors. All examples combine documented forms and were not executed."
