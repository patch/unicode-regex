notes: "Documented named-value types are script/sc, script extensions/scx and Bidi_Class/BC, with either = or :. Bare script names select Script_Extensions since 10.40. General Category uses the short bare values; long aliases such as Letter and Is prefixes are explicitly unsupported. Braces can be omitted for a one-letter category after p/P without an initial ^; braced forms enclose the ^ negation. P complements; an initial ^ also negates, and P plus ^ gives double negation. Explicit gc=/General_Category= syntax and binary =Yes/=No forms are not documented. Current binary names/abbreviations require an unavailable documentation inventory; White_Space/WSpace, Hex_Digit/Hex, Variation_Selector/VS and Deprecated/Dep are not inferred."
